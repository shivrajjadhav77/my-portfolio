# Shivraj Jadhav — Front-End Developer Portfolio

A modern, clean, responsive, and recruiter-friendly developer portfolio website built with pure HTML5, CSS3, and JavaScript ES6+.

## 🌟 Highlights

- **Clean Developer Aesthetic**: Light-theme default design with a smooth dark-theme toggle.
- **Recruiter & Job-Ready Focus**: Highlighting skills, core web applications, experience, and direct resume access.
- **Fully Responsive**: Mobile-first responsive layout tailored for desktop, tablet, and mobile screens.
- **High Performance**: Lightweight structure with zero external heavy framework dependencies.
- **Accessibility & SEO**: Built with semantic HTML, WCAG AA color contrast, visible keyboard focus states, and OpenGraph/JSON-LD metadata.

## 🛠 Tech Stack

- **HTML5**: Semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3**: CSS Custom Properties (Tokens), Flexbox, CSS Grid, Media Queries, light/dark mode styling
- **JavaScript (ES6+)**: Theme switcher, mobile drawer navigation, active link scroll highlighting, contact form validation

## 📁 Project Structure

```
my-portfolio/
├── index.html        # Main HTML structure with semantic sections & SEO metadata
├── styles.css        # Modular CSS design system & light/dark theme variables
├── script.js        # Interactive features (theme toggle, mobile nav, form validation)
├── README.md         # Documentation
└── assets/           # Images & assets
```

## 🚀 Customization Guide

1. **Personal Information**: Update name, bio, social links, and email in `index.html`.
2. **Resume**: Replace the Google Drive / PDF link in `index.html` with your resume file location.
3. **Projects**: Customize the 4 project cards in `index.html` with your actual project titles, descriptions, GitHub links, and live demo URLs.
4. **Skills**: Add or modify tech tags under `#skills` in `index.html`.

## 🌐 Local Development

To run locally, simply open `index.html` in your preferred browser, or use a local dev server such as Live Server in VS Code.
